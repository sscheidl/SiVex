# Virtuelles Titrationslabor

**GitHub-Status: Quellcodeübernahme aus lokalem Starterpaket ausstehend.**

Geplante bzw. lokal bereits prototypisch umgesetzte Funktionen: Titration starker Säuren/Basen mit frei einstellbaren Konzentrationen und Volumina, Bürettenbedienung, Indikatorfarbwechsel, zuschaltbare pH-Kurve und quantitative Konzentrationsbestimmung.

Die grafische Qualität und die chemische Korrektheit sind vor einer fachlichen Freigabe unabhängig zu verifizieren. Die lokale Version enthält Tests, aber ein bestandener Testlauf ersetzt keine Abnahme im mebis-Kurs.
